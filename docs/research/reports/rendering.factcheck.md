## OMISSIONS
- How Remotion counts renders is partly answered in its own source. In Remotion Lambda, each chunk calls renderMedia() with licenseKey: null (packages/serverless/src/handlers/renderer.ts), and the launch function sends one usage event per finished video. A self-hosted chunked or per-scene renderer can do the same: render chunks without a key and call @remotion/licensing registerUsageEvent() once per delivered video. Get Remotion to confirm in writing; done that way, per-scene caching need not multiply license cost.
- Remotion's official Maps guide (docs/maps.mdx) recommends --gl=angle and --concurrency=1 for WebGL-heavy map renders, and warns about memory leaks with angle. That means one map tab per browser per box. The '10–50 frames/s per GPU box' estimate may be optimistic, so the spike should measure fps at concurrency 1 and try running several Chrome processes per GPU.
- Remotion ships an official 'Prompt to Motion Graphics SaaS Starter Kit' (npx create-video --template prompt-to-motion-graphics), LLM code-generation and just-in-time compilation guides, Agent Skills, and a MapLibre + Turf maps guide. These directly speed up the MVP and were not mentioned.
- Do not classify customer-facing low-res drafts as 'development' renders. The v5 terms rely on honest self-reporting and production/development flags, and misreporting counts as piracy, with 10% per month interest on unpaid fees.
- The Free License threshold counts 'people/personnel', including part-time staff, contractors and any agency that co-operates the codebase, not only employees. Outsourcing development can push the company over 3.
- Cheaper compute options the report missed: Cloud Run Worker Pools (CPU $0.000011244/vCPU-s, cheaper than Jobs or Delayed Jobs, same L4 price) for a queue-driven render fleet; g6f.large at $0.202/h; g4dn.xlarge 1-year reserved at $0.331/h; and Spot Advisor data showing g6.xlarge spot is interrupted more than 20% of the time (avoid it) while g6f and g4dn are more stable.
- Codec patents and FFmpeg licensing: the Remotion license does not cover H.264, HEVC or AAC patent royalties (FAQ and Terms, Third-party rights). Remotion's bundled FFmpeg is GPLv2+ because of x264/x265. That is fine for server-side SaaS but matters if you ever ship a desktop or Electron app. Consider avoiding HEVC, and offer royalty-free VP9/AV1 + Opus where it makes sense.
- Map data licensing is separate from renderer licensing. MapLibre and PMTiles are BSD-3, but OSM-derived basemaps (Protomaps) require visible '© OpenStreetMap contributors' attribution in the videos. Natural Earth is public domain and ideal for flat history maps. The popular aourednik/historical-basemaps border dataset is GPL-3.0, which is legally ambiguous for commercial output. Satellite and terrain imagery each have their own terms.
- R2 Infrequent Access has a 30-day minimum storage duration and 2–2.5x higher operation prices, so lifecycle rules that move short-retention finals to IA can raise cost.
- Client-side (WebCodecs) rendering sends each end user's IP and domain to Remotion for telemetry. This needs a privacy-policy and GDPR disclosure, and every client render is billable under Automators.
- HyperFrames, as a hedge, now has its own Player package, a GCP Cloud Run deploy package and HeyGen-hosted cloud rendering, which narrows Remotion's Player advantage. Revideo's repository moved to the midrender org.
- Hidden AWS costs beyond Lambda compute: S3 storage and egress for assets pulled over HTTP, CloudWatch logs, extra ephemeral storage (v5 defaults to 10 GB disk), and the need to request a concurrency quota increase on new accounts, which may start far below 1,000.
- Fractional g6f GPUs and Cloud Run L4 have not been shown to expose graphics APIs (Vulkan/EGL) to Chrome. The report flags this, but those are the two cheapest GPU paths in its cost tables. Treat them as unproven until the spike passes, and budget with g4dn.xlarge, Remotion's documented path.

## RELIABILITY
Mostly reliable. I could check every decision-critical claim against a primary source, and they hold. The Remotion license terms, prices and AI-SaaS permission match the official terms, FAQ and source code. AWS Lambda, EC2, Cloud Run and R2 prices match their official price lists to the cent. The --gl, GPU, NVENC, client-side and Lambda-limit claims match Remotion's docs, and the npm release dates are exact. The main errors are in characterization and interpretation, not prices. The Lambda cost examples are video-in-video renders, not simple compositions, so the CPU calibration is off. Suggesting customer drafts be flagged as development renders is a compliance risk. The free-tier threshold counts people, including contractors, not just employees. The report also missed Remotion's own map-rendering guidance (concurrency=1), which may make the GPU throughput estimates optimistic. The open question about chunk license counting is partly answered by Remotion's source code. Everything labeled SNIPPET (Hetzner, Modal, RunPod, GEX44, B2, Bunny, Mux, the render APIs, the GSAP clause) remains unverified, because those sites were also blocked during this check. All per-minute cost figures are still estimates until the spike measures real frame times.
