# AI Map-Story Video Generator (working name)

This is a SaaS that turns a topic, or a pasted script, into a finished, narrated map-animation video. The videos tell geography, history and geopolitics stories with:
- animated maps: camera flights, borders through time, army arrows, routes;
- motion graphics and weather effects;
- voice, music and captions.

It offers many visual styles and vertical, horizontal and square formats.

**Status:** planning complete; building has not started.
